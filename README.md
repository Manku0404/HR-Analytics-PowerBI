# HR Analytics & Employee Attrition Dashboard  Power BI

## 📊 Project Overview

This project presents an interactive HR Analytics Dashboard built using Microsoft Power BI.

The objective of this project is to analyze employee attrition and workforce characteristics and provide HR-focused insights through interactive KPIs, visualizations, and filters.

The dashboard helps analyze attrition across departments, job roles, age groups, education fields, gender, and overtime.

---

## 🎯 Business Objective

The main objective of this project is to understand employee attrition patterns and identify workforce segments that may require further HR investigation.

Key business questions include

- How many employees are currently in the organization
- How many employees have left the organization
- What is the overall attrition rate
- Which departments have the highest attrition
- Which job roles experience higher attrition
- How does attrition vary across different age groups
- What is the attrition distribution by gender
- Does overtime appear to be associated with employee attrition
- How does employee education background vary across attrition cases

## 🔍 Key Analysis

### Department Analysis

The dashboard compares employee attrition across different departments to identify departments with relatively higher attrition.

### Job Role Analysis

Attrition is analyzed across individual job roles to identify roles with higher employee exits.

### Age Group Analysis

The dashboard analyzes attrition across different employee age groups to identify workforce segments with higher attrition counts.

### Gender Analysis

The dashboard provides a gender-based view of employee attrition.

### Overtime Analysis

The dashboard compares employee attrition between employees working overtime and those who do not.
